## Color System

### Quality Score Gradients
```
High (90+):    #f093fb → #f5576c  (Pink)
Medium (80-89): #667eea → #764ba2  (Purple) 
Good (<80):     #4facfe → #00f2fe  (Blue)
```

## Interaction Flow

```
User Journey:
┌──────────────────────────────────────────────────────────┐
│                                                          │
│  1. Open App                                             │
│     └→ See Overview Screen                               │
│        └→ Scroll down                                    │
│           └→ See Progress Story Card                     │
│                                                          │
│  2. First Time User                                      │
│     └→ See "Coming Soon" teaser                          │
│        └→ Builds anticipation                            │
│           └→ Complete session                            │
│              └→ Receive reel notification                │
│                 └→ Card updates with preview             │
│                                                          │
│  3. Returning User                                       │
│     └→ See latest reel preview                           │
│        └→ [Option A] Tap card                            │
│        │   └→ Opens reel modal                           │
│        │      └→ View carousel                           │
│        │         └→ Share via native sheet               │
│        │                                                  │
│        └→ [Option B] Tap history button                  │
│            └→ Opens gallery screen                       │
│               └→ Browse all reels                        │
│                  └→ Tap any card                         │
│                     └→ Opens reel modal                  │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

## Technical Flow

```
Data Flow:
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  Firestore: /reels/{reelId}                             │
│             ↓                                           │
│  Service:   progressReelService.getUserReels()          │
│             ↓                                           │
│  Hook:      useReelHistory()                            │
│             ├→ reels[]                                  │
│             ├→ latestReel                               │
│             ├→ hasReels                                 │
│             └→ loading                                  │
│             ↓                                           │
│  Component: <ProgressStoryCard />                       │
│             ├→ Render card with preview                 │
│             └→ Navigate to /progressReel or /reelHistory│
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## Performance

```
Optimization:
- useReelHistory hook memoizes queries
- FlatList for efficient gallery rendering
- Image-free carousel (text only for now)
- Pull-to-refresh prevents unnecessary fetches
- 10-reel limit keeps query fast (<100ms)

Load Times (Target):
- Card render:     <50ms
- History load:    <200ms
- Modal open:      <100ms
- Pull-to-refresh: <500ms
```
