## 🐛 Troubleshooting

### Card Doesn't Appear
**Check:**
1. Feature flag enabled: `progressReel: { enabled: true }`
2. User is authenticated (logged in)
3. No console errors

**Fix:**
```typescript
// Check feature flag in app/src/config/featureFlags.ts
progressReel: {
  enabled: true, // Must be true
},
```

### "Coming Soon" Shows When You Have Reels
**Cause:** Firestore query not returning reels

**Check:**
1. Open Firebase Console → Firestore
2. Navigate to `/reels` collection
3. Verify `userId` matches your auth UID
4. Verify `status: 'ready'`

**Fix:**
```bash
# Check console logs
console.log('User ID:', user.uid);
console.log('Reels fetched:', reels.length);
```

### Gradient Not Rendering
**Cause:** `expo-linear-gradient` not installed

**Fix:**
```bash
cd app
pnpm install expo-linear-gradient
# If on iOS:
cd ios && pod install && cd ..
```

### History Screen Empty
**Cause:** No reels in database OR query failing

**Check:**
1. Open History screen
2. Check console for errors
3. Verify Firestore rules allow read access to `/reels`

**Rules should include:**
```javascript
match /reels/{reelId} {
  allow read: if request.auth != null && 
    request.auth.uid == resource.data.userId;
}
```

## 📊 Generating Test Data

### Create Test Reel (Manual)
**Firebase Console:**
1. Go to Firestore
2. Click `/reels` collection → Add Document
3. Use this data:

```json
{
  "reelId": "reel_test_123",
  "userId": "YOUR_USER_ID_HERE",
  "sessionId": "session_test_123",
  "highlights": [
    "Student mastered solving quadratic equations using factoring",
    "Demonstrated excellent understanding of the discriminant concept",
    "Successfully applied the quadratic formula to real-world problems"
  ],
  "qualityScore": 92,
  "sentiment": "positive",
  "imageUrls": [],
  "referralLink": "https://messageai.app/r/test123",
  "createdAt": "2025-11-04T12:00:00Z",
  "expiresAt": "2025-12-04T12:00:00Z",
  "status": "ready"
}
```

**Important:** Replace `YOUR_USER_ID_HERE` with your actual Firebase Auth UID.

### Create Multiple Test Reels
Repeat the above with different:
- `reelId` (must be unique)
- `qualityScore` (try 85, 92, 78 for different colors)
- `sentiment` ('positive', 'neutral', 'challenging')
- `createdAt` (different dates)

## 🔧 Development Mode

### Hot Reload Testing
The card and history screen support hot reload:

1. Start app: `pnpm start`
2. Open `ProgressStoryCard.tsx`
3. Change colors, text, spacing
4. Save → See instant update
5. No need to reload app

### Console Logging
Check these logs:
```
📥 Fetching user reels
✅ User reels fetched: { count: 3 }
🎥 Navigating to progress reel: reel_123
```

**Enable verbose logs:**
```typescript
// In useReelHistory.ts, add:
console.log('Reels state:', { reels, loading, error });
```
