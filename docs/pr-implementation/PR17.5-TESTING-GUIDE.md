# PR17.5 Personalization Agent - Testing Guide

## Quick Test (2 minutes)

### Test 1: English (Default)

1. Open the iOS simulator
2. Log in as a **Tutor**
3. Click "📇 Test PR18 Tutor Card" button
4. **Expected:** Modal title shows "Share your 5⭐ rating with potential students!"

### Test 2: Spanish Localization

1. Open Firebase Console → Firestore
2. Navigate to: `users/{your-tutor-uid}`
3. Add field: `locale` = `es` (type: string)
4. **Reload the app** (close and reopen in simulator)
5. Click "📇 Test PR18 Tutor Card" button
6. **Expected:** Modal title shows "¡Comparte tu calificación de 5⭐ con estudiantes potenciales!"

---

### Test 3: French Localization

2. Change field: `locale` = `fr`

### Test 4: Persona Differences

## Troubleshooting

**Issue:** Copy doesn't change after setting locale  
**Fix:** Make sure to **fully reload the app** (close and reopen simulator)

**Issue:** Getting English even with `locale: 'es'`  
**Fix:** Check that the locale field is a **string** type in Firestore, not a map or other type

**Issue:** Seeing "undefined" or empty title  
**Fix:** Check console logs for errors. The hook should always return a fallback value.
